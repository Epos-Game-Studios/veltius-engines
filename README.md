# Veltius engine clients

Read a Veltius project from a game engine's editor and follow its change feed,
through the endpoint the Veltius desktop app runs on 127.0.0.1.

- Voltage: the Veltius plugin, as `com.veltius.voltage-X.Y.Z.zip` on the
  `voltage-vX.Y.Z` releases. Name that zip as the plugin's `Source.Zip` in the
  game's `plugins.json`.
- Godot 4.3 and later, Lua and C#: published from here as their releases land.

This repository is published from the Veltius source on each release, so
changes made here are overwritten.
